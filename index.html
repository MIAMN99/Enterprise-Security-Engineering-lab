01 / PROJECT OVERVIEW

Security by design.

Documenting the configuration workflow from identity definitions through access decisions and validation.

THE OBJECTIVE

Control who can access what.

This lab explores how an enterprise identity and policy platform can organize users and devices, define authentication and authorization logic, and apply network access restrictions.

The repository includes configuration screenshots that document the implementation stages. Detailed topology and test results can be added as the lab evolves.
